# Tasks

## Conventions
- **Blocking rules (reviewer treats violations as blocking):** code checks run before the judge; the judge fails closed; never send lab values to the judge or generator unless the task requires it (D5); no new dependencies without a reason in the commit; never weaken or delete a test to get green; labels are never generated by Claude.
- **Commands:** `uv run pytest`, `uv run ruff check .`, `uv run pyright`.
- **Done when** every box is checked, tests and lint pass, and the reviewer subagent finds nothing blocking.
- Report any AI correction or surprise for `docs/ai-log.md`.
